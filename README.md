
# 🧠 YouTube Proxy Monitoring Bot

This project is an automation bot developed using Python and Selenium. It automatically plays YouTube Shorts videos through different proxy IP addresses and allows them to be watched for a certain period of time.

## 📌 Features

- ✅ Automatic proxy connection
- ✅ Realistic video playback (play + wait)
- ✅ Bypassing broken proxies
- ✅ Proxy list is read from file (`proxy_list.txt`)
- ✅ Proxy username/password support (optional)
